================================================================================
QLOITER AUTO DESCENT — ДОКУМЕНТАЦИЯ
================================================================================
Автоматическое снижение в режиме QLoiter для квадроплейна ArduPlane.
Кастомная прошивка на базе ArduPlane 4.4.3, ветка custom-v2.0.

Файлы:
  ArduPlane/quadplane.h    — объявления класса AP_AutoHelpLand и переменных
  ArduPlane/quadplane.cpp  — вся логика: hold_auto_help_land(), параметры,
                             get_ahl_descent_rate_cms()
  ArduPlane/mode_qloiter.cpp — точка входа, вызывает hold_auto_help_land()

================================================================================
1. ПРЕДЫСТОРИЯ И ПРОБЛЕМЫ
================================================================================

Изначально была Lua-скрипт для QStabilize (v1-v7), потом портирован в C++.
Проблемы которые решались по ходу:

ПРОБЛЕМА: Барометр у земли (ниже 3-5м) дает скачки ±1-3 метра из-за
  граунд-эффекта (воздушная подушка от коптерных винтов). Это делало
  невозможным точное управление снижением по барометру.
РЕШЕНИЕ: Установлен дальномер Holybro H-Flow. В EKF3 настроен
  EK3_RNG_USE_HGT=70%, RNGFND_MAX_CM=3000.

ПРОБЛЕМА: Старый контроллер (safety-net / подушка) не командовал снижение,
  а только ограничивал скорость падения через throttle floor.
  Результат: зависание на 10-14м, рывки газа, неконтролируемое падение.
  Три зоны (не снижается / в пределах нормы / выше нормы) были реактивными
  и не обеспечивали плавное управление.
РЕШЕНИЕ: Полностью переписан на активный FF+P+I контроллер.

ПРОБЛЕМА: При посадке самолет скакал у земли (ground bounce) — касался
  земли, подушка от винтов подбрасывала на 0.5-0.7м, снова падал, цикл.
  Старый ground settle сбрасывался при каждом подскоке.
РЕШЕНИЕ: Защелка _ahl_touched_ground — как только высота ниже GND_ALT
  (дефолт 0.30м), газ только снижается и не восстанавливается до набора
  3м или дизарма.

ПРОБЛЕМА: После посадки без дизарма повторный взлет — система не работала,
  самолет падал камнем (ground_settle оставался на максимуме и срезал газ).
РЕШЕНИЕ: При наборе высоты >3м сбрасываются touched_ground, ground_settle,
  i_sum, descent_filt. Работает и при переключении режимов (QStab → QLoiter).

================================================================================
2. АРХИТЕКТУРА — КАК ЭТО РАБОТАЕТ
================================================================================

Точка входа:
  mode_qloiter.cpp → ModeQLoiter::run() → quadplane.hold_auto_help_land()

Функция hold_auto_help_land() имеет 4 ветки:

┌─────────────────────────────────────────────────────────────────────┐
│ 1. GPS + газ <= 40% + armed     → Z-контроллер ArduPilot           │
│ 2. Нет GPS + газ <= 40% + armed → FF+P+I контроллер (наш)         │
│ 3. Газ <= 0 + нет air mode      → GROUND_IDLE (моторы на холостых) │
│ 4. Всё остальное                → прямая передача газа пилоту      │
└─────────────────────────────────────────────────────────────────────┘

Порог 40% газа (thr_threshold = 0.40): если пилот дает газ выше 40%,
система не вмешивается — пилот управляет сам.

Порог активации 3м (alt_m > 3.0): система включается только после набора
3м высоты. Это предотвращает срабатывание на земле при армировании.

--- 2.1 GPS ВЕТКА ---

Использует стандартный Z-контроллер ArduPilot (тот же что в QRTL/QLand):
  - Скорость снижения берется из таблицы A_LAND_G_RT* по текущей высоте
  - pos_control->set_max_speed_accel_z() задает лимиты
  - set_climb_rate_cms() задает целевую скорость
  - run_z_controller() выполняет PID-контроллер

--- 2.2 NO-GPS ВЕТКА (основная разработка) ---

Активный FF+P+I контроллер, управляет газом напрямую:

  throttle = hover - FF * target_rate + KP * error + KI * integral - ground_settle

Где:
  hover       — газ зависания (Q_M_THST_HOVER ~0.41 или A_LAND_N_HOVR)
  FF          — feed-forward, снижает газ пропорционально целевой скорости
  target_rate — из таблицы A_LAND_N_RT* по текущей высоте (м/с)
  error       — (фактическая скорость - целевая), положительная = слишком быстро
  KP          — пропорциональный коэффициент
  KI          — интегральный коэффициент (с антивиндапом)
  integral    — накопленная ошибка (диапазон -8..8)
  ground_settle — прогрессивное снижение газа у земли

--- 2.3 ИСТОЧНИКИ ВЫСОТЫ ---

Приоритет:
  1. Дальномер (если status = Good) — прямые показания в метрах
  2. Стейл дальномер (потерян < 2 сек назад) — MAX(последнее, барометр)
  3. Барометр — fallback

Дальномер обрабатывается:
  - Slew rate limit (ниже SL_ALT): ограничивает скорость изменения
    показаний до SL_SPD м/с для фильтрации глитчей
  - Дифференцирование + EMA фильтр (tau ~0.3с) для получения
    скорости снижения по дальномеру

--- 2.4 ИСТОЧНИКИ СКОРОСТИ СНИЖЕНИЯ ---

Приоритет:
  1. Ниже 10м + дальномер OK: blend EKF + rangefinder rate
     - Вес дальномера: 20% на 10м → 70% у земли
     - EKF уже фьюзит дальномер через EK3_RNG_USE_HGT, но прямой rate
       дает дополнительную надежность
  2. EKF velocity (ahrs.get_velocity_NED) — основной источник
  3. Rangefinder rate (только если EKF недоступен)
  4. Barometer climb rate — последний fallback

Финальная скорость фильтруется EMA (tau ~0.25с).

--- 2.5 GROUND SETTLE (ПОСАДКА) ---

Этапы:
  1. alt > 1.0м — ground_settle = 0, нормальное снижение
  2. alt < 1.0м, медленное снижение — мягкое снижение газа (5%/с, макс 15%)
  3. alt < GND_ALT (дефолт 0.30м) — ЗАЩЕЛКА: touched_ground = true
  4. После защелки — агрессивное снижение газа (25%/с, макс 45%)
     Даже если подскочит — газ продолжает снижаться!
  5. Сброс защелки: набор >3м высоты ИЛИ дизарм

Высота шасси на земле: ~0.20м по дальномеру (задана в RNGFND параметрах).
GND_ALT = 0.30м → срабатывает на 10см выше точки касания.

--- 2.6 RE-ARM ЛОГИКА ---

При наборе высоты >3м:
  - _ahl_armed_flag = true (система активна)
  - Если touched_ground была true — полный сброс: touched_ground,
    ground_settle, i_sum, descent_filt

Это работает для:
  - Первый взлет
  - Повторный взлет без дизарма
  - Переключился в QStabilize → взлетел → переключился назад в QLoiter

================================================================================
3. ТАБЛИЦА ПАРАМЕТРОВ A_LAND_*
================================================================================

Все параметры регистрируются в ParametersG2 как A_LAND_*.
Полное имя параметра = A_LAND_ + имя ниже.

--- 3.1 СКОРОСТИ СНИЖЕНИЯ С GPS (Z-контроллер) ---

  G_RT5    = 15 см/с   Скорость на 5м и ниже (финальная посадка)
  G_RT10   = 50 см/с   Скорость на 10м (интерполяция 5-10м)
  G_RT20   = 100 см/с  Скорость на 20м (интерполяция 10-20м)
  G_RT40   = 200 см/с  Скорость на 40м (интерполяция 20-40м)
  G_RT40P  = 300 см/с  Скорость выше 40м (постоянная)

  МОЖНО МЕНЯТЬ. Это просто лимиты для Z-контроллера.
  Увеличьте если снижение слишком медленное.
  Уменьшите если слишком резкое.

--- 3.2 СКОРОСТИ СНИЖЕНИЯ БЕЗ GPS (FF+P+I контроллер) ---

  N_RT5    = 15 см/с   Целевая скорость на 5м и ниже
  N_RT10   = 50 см/с   Целевая скорость на 10м
  N_RT20   = 100 см/с  Целевая скорость на 20м
  N_RT40   = 200 см/с  Целевая скорость на 40м
  N_RT40P  = 300 см/с  Целевая скорость выше 40м

  МОЖНО МЕНЯТЬ. Контроллер будет подбирать газ чтобы снижаться
  с этой скоростью. Если не садится — увеличьте. Если бьется — уменьшите.

--- 3.3 КОЭФФИЦИЕНТЫ FF+P+I (только без GPS) ---

  N_FF   = 0.05   Feed-Forward. ГЛАВНАЯ настройка. Задает базовый уровень
                   газа: hover - FF * целевая_скорость.
                   Если снижение слишком медленное — увеличьте (0.06-0.08).
                   Если слишком быстрое — уменьшите (0.03-0.04).
                   Менять осторожно, шагами по 0.01.

  N_KP   = 0.05   P-коэффициент. Реагирует на отклонение от целевой скорости.
                   НЕ РЕКОМЕНДУЕТСЯ МЕНЯТЬ. Слишком большое — раскачка газа.

  N_KI   = 0.02   I-коэффициент. Убирает постоянную ошибку (ветер, граунд-эффект).
                   НЕ РЕКОМЕНДУЕТСЯ МЕНЯТЬ. Имеет антивиндап [-8..8].
                   Слишком большое — медленная раскачка.
                   Слишком маленькое — зависание на одной высоте.

  N_HOVR = 0      Ручной газ ховера. 0 = авто (Q_M_THST_HOVER).
                   НЕ РЕКОМЕНДУЕТСЯ МЕНЯТЬ. Только если автозначение скачет.

--- 3.4 ЗАЩИТА ДАЛЬНОМЕРА ---

  SL_ALT = 15.0м  Ниже этой высоты фильтруются показания дальномера.
                   0 = выключено. МОЖНО МЕНЯТЬ.

  SL_SPD = 5.0 м/с  Макс. скорость изменения показаний дальномера.
                     МОЖНО МЕНЯТЬ. Меньше = больше фильтрация, но отстает.

--- 3.5 ПОСАДКА ---

  GND_ALT = 0.30м  Высота определения касания земли по дальномеру.
                    Должна быть чуть выше реальной высоты шасси (0.20м).
                    Когда высота ниже — защелка, газ начинает резаться.
                    МОЖНО МЕНЯТЬ под свое шасси.

================================================================================
4. ПЕРЕМЕННЫЕ СОСТОЯНИЯ (quadplane.h)
================================================================================

  _ahl_i_sum              — интегральный аккумулятор (м/с * с)
  _ahl_descent_filt       — отфильтрованная скорость снижения (м/с, +вниз)
  _ahl_rngfnd_rate_filt   — скорость по дальномеру, фильтрованная (м/с, +вниз)
  _ahl_prev_rngfnd_alt    — предыдущая высота дальномера (для дифференцирования)
  _ahl_prev_rngfnd_ms     — время предыдущего чтения дальномера
  _ahl_last_good_rngfnd_alt — последнее хорошее чтение дальномера
  _ahl_last_good_rngfnd_ms  — время последнего хорошего чтения
  _ahl_armed_flag         — система активна (набрали 3м)
  _ahl_rngfnd_was_ok      — дальномер был OK на предыдущем цикле
  _ahl_ground_settle      — аккумулятор снижения газа у земли
  _ahl_touched_ground     — защелка: коснулись земли

Все сбрасываются при дизарме.
touched_ground, ground_settle, i_sum, descent_filt сбрасываются при наборе >3м.

================================================================================
5. ЖЕЛЕЗО И НАСТРОЙКИ EKF
================================================================================

  Дальномер: Holybro H-Flow (лидар, вниз)
  EK3_RNG_USE_HGT = 70%    — EKF использует дальномер для высоты
  RNGFND_MAX_CM = 3000      — макс. дальность 30м
  Высота шасси: ~0.20м      — на земле дальномер показывает 0.20м

  Hover throttle: Q_M_THST_HOVER ~0.41

================================================================================
6. ИЗВЕСТНЫЕ ОСОБЕННОСТИ И ОГРАНИЧЕНИЯ
================================================================================

  - Барометр ниже 3-5м дает скачки ±1-3м из-за граунд-эффекта
  - Дальномер решает проблему, но имеет макс. дальность (30м)
  - Выше дальности дальномера — только барометр и EKF
  - Ground settle — одноразовый до re-arm или дизарма
  - При повторном взлете без дизарма система полностью рабочая после 3м
  - Переключение QStab → QLoiter: система работает если высота >3м
  - GPS ветка использует стандартный Z-контроллер ArduPilot (тот же что QRTL)
  - No-GPS ветка — полностью кастомный контроллер
